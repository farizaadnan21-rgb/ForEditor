🖌️ ForEditor

Lightweight image editor · dark modern UI · portfolio ready

Python 3.10+ Tkinter Pillow OpenCV MIT License
Canvas 900 × 750
Catatan deployment: ForEditor adalah aplikasi desktop (Python + Tkinter), bukan web app di browser. Halaman ini adalah landing page portfolio di Vercel. Untuk menggunakan editor, jalankan ForEditor.py di komputer Anda (lihat di bawah).
⭐ Lihat di GitHub 📥 Cara install ✨ Fitur

Fitur utama

🛠️ Alat menggambar

Kuas bulat, kotak, spray, penghapus, pilih warna, ukuran kuas 1–50.

🎛️ Penyesuaian gambar

Kecerahan, kontras, saturasi, temperatur warna, denoise — preview langsung.

✨ Efek spesial

Sketsa pensil, cyberpunk neon, sepia vintage — toggle on/off.

↩ Produktivitas

Undo/Redo (20 langkah), load/save PNG, reset kanvas, status bar.

Menjalankan aplikasi desktop

Clone repository, install dependensi, lalu jalankan:

git clone https://github.com/farizaadnan21-rgb/ForEditor.git cd ForEditor pip install -r requirements.txt python3 ForEditor.py

Pintasan: Ctrl+Z Undo · Ctrl+Y Redo

Kenapa bukan editor di browser?

Vercel

Hosting untuk situs web statis & framework JS. Cocok untuk halaman ini.

ForEditor.py

GUI Tkinter butuh display OS lokal — tidak bisa di-render di server Vercel.

Alternatif cloud

Release GitHub (`.exe`/AppImage), Snap, atau port ke web dengan Pyodide/React terpisah.
