# 🎨 ForEditor Studio

Modern lightweight image editor built with Python Tkinter.  
Designed with a clean dark interface and portfolio-ready desktop experience.

---


---

# ✨ Features

## 🖌 Drawing Tools
- Free draw brush
- Circle brush
- Square brush
- Spray paint mode
- Adjustable brush size
- Color picker
- Eraser tool

---

## 🖼 Image Adjustment
- 🌞 Brightness control
- ⚫ Contrast enhancement
- 🎨 Saturation adjustment
- 🌡 Temperature effect (Blue / Yellow)
- 🧹 Noise reduction

---

## 🌌 Special Effects
- ✏ Pencil Sketch effect
- 🌃 Cyberpunk Neon effect
- 📜 Sepia Vintage filter

---

# 💾 Utilities
- Load image
- Save image
- Undo / Redo system
- Interactive editing canvas

---

# 🖥 Modern Interface
- Modern dark UI
- Portfolio-ready layout
- Organized sidebar tools
- Responsive workspace
- Clean desktop application design

# ⚙ Tech Stack

| Technology | Usage |
|---|---|

# 🚀 Installation

**1. Clone repository:**
```bash
git clone https://github.com/farizaadnan21-rgb/ForEditor.git
```

**2. Masuk ke folder STUDIO:**
```bash
cd STUDIO
```

**3. Install semua dependencies:**
```bash
pip install -r requirements.txt
```

---

# ▶️ Cara Menjalankan

### 🖌️ FOR Editor (Editor Foto)
```bash
python3 FOR_EDITOR/main.py
```

### 🎨 FOR Paint (Aplikasi Melukis)
```bash
python3 ForPaint.py
```
