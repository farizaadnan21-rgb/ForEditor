# 🎨 ForEditor Studio

Modern lightweight image editor built with Python Tkinter.  
Designed with a modern dark interface

# ✨ Features

## 🖌 Drawing Tools
- Free draw brush
- Circle brush
- Square brush
- Spray paint mode
- Adjustable brush size
- Color picker
- Eraser tool

---

## 🖼 Image Adjustment
- 🌞 Brightness control
- ⚫ Contrast enhancement
- 🎨 Saturation adjustment
- 🌡 Temperature effect (Blue / Yellow)
- 🧹 Noise reduction

---

## 🌌 Special Effects
- ✏ Pencil Sketch effect
- 🌃 Cyberpunk Neon effect
- 📜 Sepia Vintage filter

---

## 💾 Project Utilities
- Load image
- Save image
- Undo / Redo system
- Interactive editing canvas

---

# 🖥 Modern Interface
- Dark professional UI
- Portfolio-ready appearance
- Organized sidebar tools
- Modern button styling
- Responsive workspace layout

---

# ⚙ Tech Stack

| Technology | Usage |
|---|---|
| Python | Main programming language |
| Tkinter | GUI Framework |
| Pillow | Image processing |

# 🚀 Installation

Clone repository:

```bash
git clone https://github.com/farizaadnan21-rgb/ForEditor.git
```

Open project folder:

```bash
cd ForEditor
```

Install dependencies:

```bash
pip install pillow opencv-python numpy
```

Run application:

```bash
python3 ForEditor.py
```
