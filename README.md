# 🎨 ForEditor Studio

Designed with a clean dark interface and portfolio-ready desktop experience.

# ✨ Features

## 🖌 Drawing Tools
- Free draw brush
- Circle brush
- Square brush
- Spray paint mode
- Adjustable brush size
- Color picker
- Eraser tool

---

## 🖼 Image Adjustment
- 🌞 Brightness control
- ⚫ Contrast enhancement
- 🎨 Saturation adjustment
- 🌡 Temperature effect (Blue / Yellow)
- 🧹 Noise reduction

# 🚀 Installation

Clone repository:

```bash
git clone https://github.com/farizaadnan21-rgb/ForEditor.git
```

Open folder:

```bash
cd ForEditor
```

Install dependencies:

```bash
pip install pillow opencv-python numpy
```

Run application:

```bash
python3 ForEditor.py
```
